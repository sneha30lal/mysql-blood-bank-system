# Blood Bank Management System

## Overview
The Blood Bank Management System is a database management project developed using MySQL. The system helps manage blood donors, patients, hospitals, blood donations, blood test reports, and blood request records through a well-structured relational database.

This project demonstrates the use of:
- Database normalization
- Primary and foreign key relationships
- ER diagram design
- SQL queries and database management concepts

---

## Features
- Manage donor information
- Store patient details
- Maintain hospital records
- Track blood groups
- Record blood donations
- Store medical test reports
- Handle blood requests and request status

---

## Database Tables
The project contains the following main tables:

1. **hospital**
   - Stores hospital details

2. **bloodgroup**
   - Stores available blood groups

3. **donor**
   - Maintains donor information

4. **patient**
   - Stores patient details

5. **testreport**
   - Maintains blood test results and hemoglobin levels

6. **donation**
   - Tracks blood donation records

7. **bloodrequest**
   - Handles patient blood requests and request status
